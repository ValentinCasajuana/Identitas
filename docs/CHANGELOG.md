# Historial de cambios — IDENTITAS®

Registro legible de la evolución del proyecto. No sustituye al historial de Git:
Git guarda *qué* líneas cambiaron, esto guarda *por qué*.

Es también el documento que respalda la justificación de la evolución de los
instrumentos ante un tribunal o una revisión externa. Merece la pena mantenerlo.

**Formato:** tres líneas por cambio sustantivo. Lo más reciente arriba.

```
## AAAA-MM-DD — Ámbito
Qué cambió.
Por qué.
Versión del instrumento, si aplica.
```

Un retoque de maquetación no entra aquí. Un cambio de ítem, de umbral, de texto de
resultado o de protocolo de salvaguarda, siempre.
